ロウ配信ログ

Stream Log

配信は YouTube から3時間ごとに自動更新しています。ゲーム名はタイトル先頭の【】の中身です。ブロックや三角をタップすると詳細とリンクが開きます（銀の三角＝ポスト、金の三角＝配信告知）。右上が金色に折れているブロックはコラボ、斜線のブロックはこれからの予定、金の「締切」はグッズなどの締切です。時刻は閲覧している端末のタイムゾーンで表示されます。

予定・配信を追加

時刻・サムネイル・チャンネル名は自動で取得します。同じ時間に小柳ロウの配信があれば「コラボ相手の枠」として付き、なければ「本人の枠なし」として表示されます。

YouTube に枠が立つと、自動でそちらに置き換わります。

投稿時刻は URL から自動で読み取ります。

カレンダーの上の「締切が近いもの」と、該当日に「締切」の印で表示されます。

GitHub の画面が開くので、「Create」（Submit new issue）を押すと登録されます。カレンダーへの反映まで数分かかります。
